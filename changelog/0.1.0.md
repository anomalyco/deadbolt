- **CLI and daemon.** `deadbolt` and its background daemon, prebuilt for macOS and Linux on x64 and arm64, with a static build for musl systems. Install with `curl -fsSL https://deadbolt.pw/install | sh`, Homebrew, npm or bun.
- **Pairing.** A new device runs `deadbolt join`, and a device with the vault lets it in with `deadbolt approve <code>`. Both screens show the same six digits to confirm.
- **Sync.** Devices sync directly over [iroh](https://www.iroh.computer), end-to-end encrypted. A device that isn't a member is refused before it can send or receive a byte.
- **Updates.** `deadbolt update` installs the next release.
