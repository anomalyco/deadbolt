# Decoy pages for the detection gate: real pages whose fields are not a sign-in
# (searches, promo codes, newsletters, invites, admin and settings forms,
# comments, support forms, transfers), where no login menu should open.
# Freeze them with `bun corpus/freeze.ts --urls corpus/decoy-urls.txt --decoy`
# (network, once, never in CI), then label each one in gold-labels.jsonl.
# One URL per line, then what the trap is; # starts a comment or a section.
# Pages behind a sign-in are listed commented out: freeze.ts never signs in,
# so frozen/ has a page modeled on each instead (decoy-* in gold-labels.jsonl).
